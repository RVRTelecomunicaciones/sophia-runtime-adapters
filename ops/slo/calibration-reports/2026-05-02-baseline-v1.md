**Critical caveat (D2C4F.8 honest tiers):** the bench measures the **adapter floor** under controlled fixtures (`file://` small-repo, single-file edits, 1 VU sequential). Real-world latency depends on workload variables the bench cannot capture:

- **clone**: repo size, network speed (https/ssh handshake), history depth, packfile transfer
- **diff**: number of changed files, file sizes, binary diff complexity, diff algorithm choice

These capabilities **cannot promote to CALIBRATED** without production telemetry covering real workloads.

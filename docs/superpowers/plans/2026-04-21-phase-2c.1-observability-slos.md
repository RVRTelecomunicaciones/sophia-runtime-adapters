# Phase 2C.1 — Observability Depth + SLOs — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver the governable observability layer of `runtime-adapters`: contract-bound `slog` logger, revised metric contract with bounded cardinality, Sloth-generated SLOs for all 8 Phase 1 capabilities, hand-written infra alerts, three-tier Alertmanager routing, 1 overview + 4 per-adapter Grafana dashboards, and a CI gate that rejects any unvalidated change under `ops/`.

**Architecture:** One new internal package (`internal/infrastructure/obs/log`) for the contextual logger; a revised metric Registry in `internal/infrastructure/obs/metrics.go`; an operational artifacts tree under `ops/` (disjoint from `internal/`). The metric contract is code-defined (I23) and bounded (R16); SLOs come from Sloth build-time generation with output committed; all other observability artifacts (alerts, dashboards, routing) are hand-written for team ownership.

**Tech Stack:**
- Language: Go `1.26+` (pinned to `go1.26.2`, unchanged from Phase 1)
- Logging: stdlib `log/slog`
- Metrics / tracing: `go.opentelemetry.io/otel` (unchanged from Phase 1)
- SLO generator: `slok/sloth` (version pinned via `ops/slo/.sloth-version`)
- Prometheus tooling: `promtool` (pinned via `ops/prometheus/.prometheus-version`)
- Alertmanager tooling: `amtool` (pinned via `ops/alertmanager/.alertmanager-version`)
- Grafana: `grafana/dashboard-linter` (pinned via `ops/grafana/.dashboard-linter-version`)
- Testing: `stretchr/testify` (unchanged)
- CI: GitHub Actions (`ubuntu-latest`, Go 1.26)

package log

import (
	"fmt"
	"os"
	"strconv"
)

// Config tunes the Logger. Zero values fall back to Phase 2C.1 defaults
// (FORMAT=text, LEVEL=info, ADD_SOURCE=false). Spec §5.6.
type Config struct {
	Format    string // "text" | "json"
	Level     string // "debug" | "info" | "warn" | "error"
	AddSource bool
}

// LoadConfig reads RUNTIME_LOG_* env vars. Missing or empty → defaults.
// Invalid values cause Validate to return error.
func LoadConfig() (Config, error) {
	cfg := Config{
		Format: envOr("RUNTIME_LOG_FORMAT", "text"),
		Level:  envOr("RUNTIME_LOG_LEVEL", "info"),
	}
	raw := os.Getenv("RUNTIME_LOG_ADD_SOURCE")
	if raw == "" {
		cfg.AddSource = false
	} else {
		b, err := strconv.ParseBool(raw)
		if err != nil {
			return Config{}, fmt.Errorf("RUNTIME_LOG_ADD_SOURCE: %w", err)
		}
		cfg.AddSource = b
	}
	return cfg, cfg.Validate()
}

// Validate enforces strict enum membership per R10.
func (c Config) Validate() error {
	switch c.Format {
	case "text", "json":
	default:
		return fmt.Errorf("RUNTIME_LOG_FORMAT must be text|json, got %q", c.Format)
	}
	switch c.Level {
	case "debug", "info", "warn", "error":
	default:
		return fmt.Errorf("RUNTIME_LOG_LEVEL must be debug|info|warn|error, got %q", c.Level)
	}
	return nil
}

func envOr(key, def string) string {
	v := os.Getenv(key)
	if v == "" {
		return def
	}
	return v
}
```

package log

import (
	"context"
	"fmt"
	"io"
	"log/slog"
	"os"
)

// Logger is the contract-bound wrapper around slog.Logger. All emission
// points in the runtime flow through this type.
type Logger struct {
	inner *slog.Logger
}

// New builds a Logger from Config. cfg is validated; returns error on
// invalid enum values (R10).
func New(cfg Config) (*Logger, error) {
	if err := cfg.Validate(); err != nil {
		return nil, fmt.Errorf("log.New: %w", err)
	}
	level, err := parseLevel(cfg.Level)
	if err != nil {
		return nil, fmt.Errorf("log.New: %w", err)
	}
	opts := &slog.HandlerOptions{
		Level:     level,
		AddSource: cfg.AddSource,
	}
	var h slog.Handler
	switch cfg.Format {
	case "json":
		h = slog.NewJSONHandler(os.Stdout, opts)
	case "text":
		h = slog.NewTextHandler(os.Stdout, opts)
	default:
		// already caught by Validate; defensive
		return nil, fmt.Errorf("log.New: unreachable: format %q", cfg.Format)
	}
	return &Logger{inner: slog.New(h)}, nil
}

// NewNop returns a Logger whose output is discarded. Used as the never-nil
// default in FromContext.
func NewNop() *Logger {
	return &Logger{inner: slog.New(slog.NewTextHandler(io.Discard, nil))}
}

// With returns a derived Logger with additional attributes.
func (l *Logger) With(attrs ...slog.Attr) *Logger {
	args := make([]any, 0, len(attrs))
	for _, a := range attrs {
		args = append(args, a)
	}
	return &Logger{inner: l.inner.With(args...)}
}

// Debug emits at DEBUG level.
func (l *Logger) Debug(ctx context.Context, msg string, attrs ...slog.Attr) {
	l.emit(ctx, slog.LevelDebug, msg, attrs)
}

// Info emits at INFO level.
func (l *Logger) Info(ctx context.Context, msg string, attrs ...slog.Attr) {
	l.emit(ctx, slog.LevelInfo, msg, attrs)
}

// Warn emits at WARN level.
func (l *Logger) Warn(ctx context.Context, msg string, attrs ...slog.Attr) {
	l.emit(ctx, slog.LevelWarn, msg, attrs)
}

// Error emits at ERROR level.
func (l *Logger) Error(ctx context.Context, msg string, attrs ...slog.Attr) {
	l.emit(ctx, slog.LevelError, msg, attrs)
}

func (l *Logger) emit(ctx context.Context, lvl slog.Level, msg string, attrs []slog.Attr) {
	if !l.inner.Enabled(ctx, lvl) {
		return
	}
	args := make([]any, 0, len(attrs))
	for _, a := range attrs {
		args = append(args, a)
	}
	l.inner.Log(ctx, lvl, msg, args...)
}

func parseLevel(s string) (slog.Level, error) {
	switch s {
	case "debug":
		return slog.LevelDebug, nil
	case "info":
		return slog.LevelInfo, nil
	case "warn":
		return slog.LevelWarn, nil
	case "error":
		return slog.LevelError, nil
	default:
		return 0, fmt.Errorf("unknown level %q", s)
	}
}

package log

import "context"

type ctxKey struct{}

// ContextWith returns a new ctx carrying the given logger.
func ContextWith(ctx context.Context, l *Logger) context.Context {
	if l == nil {
		l = NewNop()
	}
	return context.WithValue(ctx, ctxKey{}, l)
}

// FromContext retrieves the Logger bound to ctx. Returns a Nop logger if
// none is bound, or if ctx is nil. NEVER returns nil (runtime invariant —
// obs must not crash the request path).
func FromContext(ctx context.Context) *Logger {
	if ctx == nil {
		return NewNop()
	}
	v := ctx.Value(ctxKey{})
	if v == nil {
		return NewNop()
	}
	l, ok := v.(*Logger)
	if !ok || l == nil {
		return NewNop()
	}
	return l
}

import (

	"github.com/sophia-ecosystem/runtime-adapters/internal/domain/execution/valueobjects"

// LevelFor maps (status, errClass) to the slog.Level emitted for the
// final per-execution log. See spec §5.4 for rationale.
func LevelFor(status valueobjects.ExecutionStatus, errClass valueobjects.ErrorClass) slog.Level {
	switch status {
	case valueobjects.StatusSuccess, valueobjects.StatusCancelled:
		return slog.LevelInfo
	case valueobjects.StatusTimeout, valueobjects.StatusPartial:
		return slog.LevelWarn
	case valueobjects.StatusFailure:
		switch errClass {
		case valueobjects.ErrValidationFailure,
			valueobjects.ErrCapabilityUnknown,
			valueobjects.ErrPayloadSchemaFailure,
			valueobjects.ErrPreconditionFailure:
			return slog.LevelInfo
		case valueobjects.ErrExternalFailure,
			valueobjects.ErrInterrupted:
			return slog.LevelWarn
		case valueobjects.ErrAdapterInternalError,
			valueobjects.ErrNormalizationFailure:
			return slog.LevelError
		}
	}
	return slog.LevelError
}

package http

import (
	"log/slog"
	"net/http"

	"github.com/oklog/ulid/v2"
	"github.com/sophia-ecosystem/runtime-adapters/internal/infrastructure/obs/log"
)

// LoggerMiddleware binds a request-scoped logger to ctx, enriched with
// correlation_id sourced from X-Correlation-Id (generated if absent).
// Order of registration in router.go: RequestID → LoggerMiddleware → panicRecoverer.
func LoggerMiddleware(root *log.Logger) func(http.Handler) http.Handler {
	if root == nil {
		root = log.NewNop()
	}
	return func(next http.Handler) http.Handler {
		return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
			corr := r.Header.Get("X-Correlation-Id")
			if corr == "" {
				corr = ulid.Make().String()
				r.Header.Set("X-Correlation-Id", corr)
			}
			reqLogger := root.With(slog.String("correlation_id", corr))
			ctx := log.ContextWith(r.Context(), reqLogger)
			next.ServeHTTP(w, r.WithContext(ctx))
		})
	}
}
```

//go:build alertmanager

package alertmanager_test

import (
	"os"
	"path/filepath"
	"strings"
	"testing"

	"github.com/stretchr/testify/require"
	"gopkg.in/yaml.v3"

type amConfig struct {
	Route struct {
		Receiver string   `yaml:"receiver"`
		GroupBy  []string `yaml:"group_by"`
		Routes   []struct {
			Matchers []string `yaml:"matchers"`
			Receiver string   `yaml:"receiver"`
		} `yaml:"routes"`
	} `yaml:"route"`
	Receivers []struct {
		Name string `yaml:"name"`
	} `yaml:"receivers"`
	InhibitRules []struct {
		SourceMatchers []string `yaml:"source_matchers"`
		TargetMatchers []string `yaml:"target_matchers"`
		Equal          []string `yaml:"equal"`
	} `yaml:"inhibit_rules"`
}

func TestAlertmanager_NullReceiverDeclared(t *testing.T) {
	cfg := loadAM(t)
	has := false
	for _, r := range cfg.Receivers {
		if r.Name == "null-receiver" {
			has = true
		}
	}
	require.True(t, has, "null-receiver must be declared")
}

func TestAlertmanager_RootReceiverExists(t *testing.T) {
	cfg := loadAM(t)
	names := map[string]bool{}
	for _, r := range cfg.Receivers {
		names[r.Name] = true
	}
	require.True(t, names[cfg.Route.Receiver], "root route receiver not declared")
	for _, r := range cfg.Route.Routes {
		require.True(t, names[r.Receiver], "sub-route receiver %q not declared", r.Receiver)
	}
}

func TestAlertmanager_GroupByIncludesCapability(t *testing.T) {
	cfg := loadAM(t)
	has := false
	for _, g := range cfg.Route.GroupBy {
		if g == "capability" {
			has = true
		}
	}
	require.True(t, has, "group_by must include 'capability' (D2C1.16)")
}

func TestAlertmanager_InhibitUsesSlothSlo(t *testing.T) {
	cfg := loadAM(t)
	require.NotEmpty(t, cfg.InhibitRules)
	found := false
	for _, ir := range cfg.InhibitRules {
		for _, eq := range ir.Equal {
			if eq == "sloth_slo" {
				found = true
			}
		}
	}
	require.True(t, found, "inhibit_rules must use sloth_slo label (D2C1.17)")
}

func TestAlertmanager_LabelsCoveredByUpstreamRules(t *testing.T) {
	cfg := loadAM(t)

	// Collect labels emitted by any rule under ops/prometheus/ (generated or rules).
	emitted := collectUpstreamLabels(t)
	emitted["severity"] = true // every rule emits severity by contract

	// Every label referenced in matchers + equal must be emitted somewhere.
	for _, ir := range cfg.InhibitRules {
		for _, eq := range ir.Equal {
			require.True(t, emitted[eq],
				"inhibit_rules.equal label %q not emitted by any upstream rule", eq)
		}
	}
	for _, r := range cfg.Route.Routes {
		for _, m := range r.Matchers {
			lbl := strings.Split(m, `=`)[0]
			lbl = strings.TrimSpace(strings.TrimSuffix(lbl, `!`))
			require.True(t, emitted[lbl],
				"route matcher label %q not emitted by any upstream rule", lbl)
		}
	}
}

func loadAM(t *testing.T) amConfig {
	data, err := os.ReadFile("alertmanager.yaml")
	require.NoError(t, err)
	var cfg amConfig
	require.NoError(t, yaml.Unmarshal(data, &cfg))
	return cfg
}

func collectUpstreamLabels(t *testing.T) map[string]bool {
	t.Helper()
	labels := map[string]bool{}

	ruleFiles, _ := filepath.Glob("../prometheus/rules/*.yaml")
	slothFiles, _ := filepath.Glob("../prometheus/generated/*.yaml")
	all := append(ruleFiles, slothFiles...)

	for _, f := range all {
		data, err := os.ReadFile(f)
		if err != nil {
			continue
		}
		// Very lax: any line matching `key:` under labels/annotations block.
		for _, line := range strings.Split(string(data), "\n") {
			trimmed := strings.TrimSpace(line)
			if strings.HasSuffix(trimmed, ":") || !strings.Contains(trimmed, ":") {
				continue
			}
			if strings.HasPrefix(trimmed, "-") {
				continue
			}
			key := strings.TrimSpace(strings.Split(trimmed, ":")[0])
			if key != "" && !strings.Contains(key, " ") {
				labels[key] = true
			}
		}
	}
	return labels
}

// Helpers ---

func readAllDashboards(t *testing.T) []dashboard {
	t.Helper()
	matches, err := filepath.Glob("dashboards/*.json")
	require.NoError(t, err)
	out := make([]dashboard, 0, len(matches))
	for _, f := range matches {
		out = append(out, readDashboard(t, filepath.Base(f)))
	}
	return out
}

func readDashboard(t *testing.T, name string) dashboard {
	t.Helper()
	data, err := os.ReadFile(filepath.Join("dashboards", name))
	require.NoError(t, err)
	var d dashboard
	require.NoError(t, json.Unmarshal(data, &d))
	return d
}

func collectEmittedNames(t *testing.T) map[string]bool {
	t.Helper()
	out := map[string]bool{}
	matches, _ := filepath.Glob("../prometheus/rules/*.yaml")
	slothMatches, _ := filepath.Glob("../prometheus/generated/*.yaml")
	all := append(matches, slothMatches...)
	re := regexp.MustCompile(`^\s+-\s+(?:record|alert):\s+(.+)$`)
	for _, f := range all {
		data, err := os.ReadFile(f)
		if err != nil {
			continue
		}
		for _, line := range strings.Split(string(data), "\n") {
			if m := re.FindStringSubmatch(line); m != nil {
				out[strings.TrimSpace(m[1])] = true
			}
		}
	}
	return out
}

# Logger contract — runtime-adapters

Canonical reference for the `internal/infrastructure/obs/log` package.

## Principle

Every log emitted within the runtime execution flow carries a **fixed
set of fields** derived from `ExecutionRequest` and `ExecutionReceipt`.
No sprintf. No payload bodies. No `request_id` as runtime-level field.

## Contract fields

| Field | Presence |
|---|---|
| `capability` | always (step 3+) |
| `adapter` | always (step 3+) |
| `correlation_id` | always (step 1+, sourced from `X-Correlation-Id` or generated ULID) |
| `handle_id` | always (step 5+) |
| `status` | always (step 7+) |
| `receipt_id` | always (step 8+) |
| `duration_ms` | always (step 11, final emit) |
| `trace_id` | when span active |
| `error_class` | when `status != success` |

## Level mapping

`LevelFor(status, errClass)` in `levels.go`:

- `success`, `cancelled` → INFO
- `timeout`, `partial` → WARN
- `failure` + caller-fault errClass → INFO
- `failure` + transient errClass → WARN
- `failure` + invariant-violation errClass → ERROR

Orthogonal emissions (persistence failure, panic recovery, migrate
failure) are always ERROR.

## Configuration

Env vars (R10 strict validation at startup):

- `RUNTIME_LOG_FORMAT` = `text` | `json` (default: `text`; `json` forced in ops)
- `RUNTIME_LOG_LEVEL` = `debug` | `info` | `warn` | `error` (default: `info`)
- `RUNTIME_LOG_ADD_SOURCE` = `false` | `true` (default: `false`)

## Context propagation

`log.ContextWith(ctx, logger)` / `log.FromContext(ctx)`. FromContext never
returns nil (returns a Nop logger if missing). The HTTP middleware chain
registers `RequestID → LoggerMiddleware → panicRecoverer`.

- Sloth generates recording + alerting rules from `ops/slo/*.yaml` →
  `ops/prometheus/generated/slo_rules.yaml` (checked in).
- Burn rate: 2 windows per SLO — fast (2% budget/1h) → `severity: critical`,
  slow (5% budget/6h) → `severity: warning`.
- Budget: 30d rolling.
- `cancelled` and `partial` are **neutral** to the availability SLI;
  `failure` and `timeout` burn budget.
- Latency histogram is **success-only**; p99 threshold per capability.

# ADR 0006 — Metric contract invariants (R16 + I23)

## Status

Accepted — 2026-04-21.

## Context

Phase 1's 11-instrument Registry had no formal invariant protecting it
from (a) unbounded-cardinality labels (e.g. `error_class`, `receipt_id`)
leaking in and (b) collector/relabel rules redefining names outside the

deployments.

  (`capability`, `adapter`, `status`, `signal`). High-cardinality labels
  prohibited; belong in logs or exemplars. CI-enforced.

  truth. Operational components may not rename/filter/drop declared
  instruments.

## Consequences

- `error_class` moves from metric label to log field.
- Dashboards refer to exact recording-rule names from
  `ops/prometheus/generated/slo_rules.yaml` — no naming guesswork.
- Rename/remove of an instrument = ADR + schema version bump.

## References

- I23 added to `docs/domain-invariants.md`.

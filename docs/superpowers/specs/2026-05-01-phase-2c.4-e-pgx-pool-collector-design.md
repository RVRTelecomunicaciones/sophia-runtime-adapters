# Phase 2C.4 / E — pgx pool Prometheus collector

> **Parent:** Phase 2C (hardening), track 4 of 4 (operational readiness),
> sub-project E of A-H (per `docs/phase-2c.4-roadmap.md`).
> **Closes at tag:** `v0.6.0`.
> **Status:** ACCEPTED 2026-05-01.
> **Authors / approvers:** Russell + assistant (brainstorming session

## 1. Summary

Sub-project E wires `pgxpool.Pool.Stat()` to OTel observable instruments
so that pool-level signals reach Prometheus. Six curated metrics under
the `runtime_adapters.pgx_pool.*` namespace. Hand-rolled OTel observables
— no third-party deps. The dormant `PoolIdleZero` alert (declared in
2C.1, never fired because the underlying metric was missing) starts
working: its selector switches from the placeholder name
`pgx_pool_idle_conns` to the namespaced `runtime_adapters_pgx_pool_idle_conns`.

No new SLOs, no new labels, no metric-contract surface change beyond the
6 new instrument registrations. The contract tests added in B8 / G are
not affected. Existing histogram
`runtime_adapters.pool.connections.acquired.duration` stays as-is —
complementary to (not duplicated by) the new counters.

## 2. Goals / non-goals

### Goals

- **G1.** Expose 6 pool stats via OTel observable instruments under the
  `runtime_adapters.pgx_pool.*` prefix, zero labels, hand-rolled.
- **G2.** Single `RegisterCallback` so all 6 instruments observe values
  from ONE `pool.Stat()` snapshot per export tick (no torn-read across
  fields).
- **G3.** Update `ops/prometheus/rules/infra_pool.yaml` so `PoolIdleZero`
  selects `runtime_adapters_pgx_pool_idle_conns` (the actual exposed
  Prom name) and remove the "DORMANT IN PRODUCTION (2C.1)" comment
  block, replacing it with a one-line back-pointer to the new collector.
- **G4.** Test the collector with a true unit test (no testcontainers,
  no real Postgres) by injecting a `func() PoolStatSnapshot` closure.
- **G5.** Ship `v0.6.0` with CHANGELOG entry. Smoke verification under
  the 2C.2 load envelope is recorded in the CHANGELOG (manual or
  scripted, NOT a recurring CI gate).

### Non-goals

- **NG1.** Exposing the other 6 `pgxpool.Stat()` fields
  (`ConstructingConns`, `CanceledAcquireCount`, `NewConnsCount`,
  `MaxIdleDestroyCount`, `MaxLifetimeDestroyCount`, `AcquireDuration`).
  Add as a follow-up bundle if dashboards or future SLOs demand.
- **NG2.** Pool config tuning (`max_connections`, idle timeout, etc.).
  Operator decision, not code.
- **NG3.** New SLOs for pool saturation. `empty_acquire_count_total`
  is exposed as a counter; defining a burn-rate alert on it is a
  future sub-project.
- **NG4.** Modifying `PoolAcquireLatencyHigh` or `PoolConnectionsExhausted`
  alert rules — those use the existing `acquired.duration` histogram
  and work today.
- **NG5.** Updating the `runtime-overview.json` dashboard to add pool
  panels. Dashboard work tracked separately.
- **NG6.** Adding any third-party pgx OTel/Prometheus instrumentation
  package (e.g. `otelpgx`).
- **NG7.** Adding labels to the new pool metrics (the pool is global;
  per-call labels would inflate cardinality without operational value).

## 3. Design principles

- **P1 — Zero new dependencies.** All wiring uses
  `go.opentelemetry.io/otel/metric` (already in the module) and
  `github.com/jackc/pgx/v5/pgxpool` (already in the module).
- **P2 — Single Stat() snapshot per export tick.** The OTel SDK's
  `RegisterCallback` lets one callback observe multiple instruments;
  we exploit this so all 6 metrics report values from ONE call to
  `pool.Stat()`. No torn read across the 6 fields.
- **P3 — Counters emit cumulative values.** `pgxpool.Stat()`
  returns monotonically-increasing cumulative counts (not deltas).
  We pass these through unchanged via `ObserveInt64`. The Prometheus
  exporter and `rate()` at query time compute deltas — we do NOT
  compute deltas in the collector. This is the OTel-canonical semantic
  for `Int64ObservableCounter`.
- **P4 — Closure-based abstraction for testability.** The collector
  takes a `func() PoolStatSnapshot` rather than `*pgxpool.Pool`
  directly. Production wires the closure as
  `func() PoolStatSnapshot { return snapshotFromPgx(pool.Stat()) }`.
  Tests wire arbitrary closures returning controlled snapshots. This
  enables a true unit test (no testcontainers, no real Postgres) and
  decouples our metric contract from pgx-specific types (`*pgxpool.Stat`
  has unexported fields and cannot be constructed in tests).
- **P5 — R16 cardinality bounded.** All 6 metrics carry zero labels.
  The pool is process-global. Labels would not give operationally
  meaningful breakdowns.
- **P6 — Lifecycle-clean.** The collector exposes a `Close()` method
  that calls `metric.Registration.Unregister()`. Bootstrap calls
  `Close()` before `pool.Close()` on shutdown, preventing the SDK
  from holding a callback that closes over a torn pool.

## 4. Component layout

### 4.1 New file: `internal/infrastructure/obs/pgxpool_collector.go`

```go
package obs

import (
    "context"
    "fmt"

    "github.com/jackc/pgx/v5/pgxpool"
    "go.opentelemetry.io/otel/metric"
)

// PoolStatSnapshot is the project-internal value type for one
// point-in-time view of pgxpool stats. Decouples our metric contract
// from pgx-specific *pgxpool.Stat (which has unexported fields and
// cannot be constructed in tests). Field types match what the OTel
// instruments accept (int64).
type PoolStatSnapshot struct {
    IdleConns         int64
    MaxConns          int64
    TotalConns        int64
    AcquiredConns     int64
    AcquireCount      int64 // cumulative monotonic
    EmptyAcquireCount int64 // cumulative monotonic
}

// PoolStatProvider returns a snapshot. Production wires this against
// pgxpool.Pool.Stat(); tests wire a closure returning fixed values.
type PoolStatProvider func() PoolStatSnapshot

// PgxPoolCollector wires PoolStatSnapshot values to OTel observable
// instruments under the runtime_adapters.pgx_pool.* namespace. Six
// metrics, zero labels, all observed in ONE callback so they share a
// single Stat() snapshot per export tick (P2 — no torn read).
type PgxPoolCollector struct {
    snapshotFn        PoolStatProvider
    idleConns         metric.Int64ObservableGauge
    maxConns          metric.Int64ObservableGauge
    totalConns        metric.Int64ObservableGauge
    acquiredConns     metric.Int64ObservableGauge
    acquireCount      metric.Int64ObservableCounter
    emptyAcquireCount metric.Int64ObservableCounter
    registration      metric.Registration
}

// NewPgxPoolCollector constructs and registers the collector against the
// supplied meter. Each instrument's name maps directly to a field on
// PoolStatSnapshot — see the inline mapping below.
func NewPgxPoolCollector(meter metric.Meter, snapshotFn PoolStatProvider) (*PgxPoolCollector, error) {
    if snapshotFn == nil {
        return nil, fmt.Errorf("pgxpool collector: snapshotFn must not be nil")
    }
    c := &PgxPoolCollector{snapshotFn: snapshotFn}

    var err error
    // ---- Gauges (current state) ----
    if c.idleConns, err = meter.Int64ObservableGauge(
        "runtime_adapters.pgx_pool.idle_conns",
        metric.WithDescription("pgxpool.Stat().IdleConns — connections currently idle in the pool."),
        metric.WithUnit("{connections}"),
    ); err != nil {
        return nil, fmt.Errorf("idle_conns: %w", err)
    }
    if c.maxConns, err = meter.Int64ObservableGauge(
        "runtime_adapters.pgx_pool.max_conns",
        metric.WithDescription("pgxpool.Stat().MaxConns — pool capacity ceiling."),
        metric.WithUnit("{connections}"),
    ); err != nil {
        return nil, fmt.Errorf("max_conns: %w", err)
    }
    if c.totalConns, err = meter.Int64ObservableGauge(
        "runtime_adapters.pgx_pool.total_conns",
        metric.WithDescription("pgxpool.Stat().TotalConns — connections currently in the pool (idle + acquired + constructing)."),
        metric.WithUnit("{connections}"),
    ); err != nil {
        return nil, fmt.Errorf("total_conns: %w", err)
    }
    if c.acquiredConns, err = meter.Int64ObservableGauge(
        "runtime_adapters.pgx_pool.acquired_conns",
        metric.WithDescription("pgxpool.Stat().AcquiredConns — connections currently in use by callers."),
        metric.WithUnit("{connections}"),
    ); err != nil {
        return nil, fmt.Errorf("acquired_conns: %w", err)
    }
    // ---- Counters (cumulative monotonic — P3) ----
    if c.acquireCount, err = meter.Int64ObservableCounter(
        "runtime_adapters.pgx_pool.acquire_count",
        metric.WithDescription("pgxpool.Stat().AcquireCount — cumulative successful acquires since pool startup."),
        metric.WithUnit("{acquires}"),
    ); err != nil {
        return nil, fmt.Errorf("acquire_count: %w", err)
    }
    if c.emptyAcquireCount, err = meter.Int64ObservableCounter(
        "runtime_adapters.pgx_pool.empty_acquire_count",
        metric.WithDescription("pgxpool.Stat().EmptyAcquireCount — cumulative acquires that found the pool empty (saturation marker)."),
        metric.WithUnit("{acquires}"),
    ); err != nil {
        return nil, fmt.Errorf("empty_acquire_count: %w", err)
    }

    // P2 — one callback observes all 6 from a single snapshot.
    c.registration, err = meter.RegisterCallback(c.observe,
        c.idleConns, c.maxConns, c.totalConns, c.acquiredConns,
        c.acquireCount, c.emptyAcquireCount,
    )
    if err != nil {
        return nil, fmt.Errorf("register callback: %w", err)
    }
    return c, nil
}

// observe is the registered callback. ONE Stat() snapshot per call;
// all 6 instruments observed from the same view (P2).
func (c *PgxPoolCollector) observe(_ context.Context, o metric.Observer) error {
    s := c.snapshotFn()
    o.ObserveInt64(c.idleConns, s.IdleConns)
    o.ObserveInt64(c.maxConns, s.MaxConns)
    o.ObserveInt64(c.totalConns, s.TotalConns)
    o.ObserveInt64(c.acquiredConns, s.AcquiredConns)
    o.ObserveInt64(c.acquireCount, s.AcquireCount)
    o.ObserveInt64(c.emptyAcquireCount, s.EmptyAcquireCount)
    return nil
}

// Close unregisters the callback. Safe to call multiple times.
// Bootstrap calls this before pool.Close() so the SDK does not retain
// a callback that closes over a torn pool.
func (c *PgxPoolCollector) Close() error {
    if c.registration == nil {
        return nil
    }
    err := c.registration.Unregister()
    c.registration = nil
    return err
}

// SnapshotFromPgx is the production wrapper: convert a *pgxpool.Stat
// to PoolStatSnapshot. Cumulative counter fields are read directly
// (P3 — no delta computation here; OTel + Prom handle rates at query
// time). Gauge fields are read as int32 and widened to int64 — pgx
// exposes them as int32 but OTel observables are int64-keyed and the
// pool will never realistically exceed int32 anyway.
func SnapshotFromPgx(s *pgxpool.Stat) PoolStatSnapshot {
    return PoolStatSnapshot{
        IdleConns:         int64(s.IdleConns()),
        MaxConns:          int64(s.MaxConns()),
        TotalConns:        int64(s.TotalConns()),
        AcquiredConns:     int64(s.AcquiredConns()),
        AcquireCount:      s.AcquireCount(),
        EmptyAcquireCount: s.EmptyAcquireCount(),
    }
}
```

### 4.4 New file: `internal/infrastructure/obs/pgxpool_collector_test.go`

True unit test using a fake `PoolStatProvider`:

```go
//go:build unit || !integration

package obs_test

import (
    "context"
    "testing"

    "github.com/stretchr/testify/require"
    sdkmetric "go.opentelemetry.io/otel/sdk/metric"
    "go.opentelemetry.io/otel/sdk/metric/metricdata"

    "github.com/sophia-ecosystem/runtime-adapters/internal/infrastructure/obs"
)

// TestPgxPoolCollector_AllSixMetricsObservedFromSingleSnapshot verifies
// the contract from spec §3 P2: one Stat() snapshot per callback,
// all 6 metrics emitted with the snapshot's field values.
func TestPgxPoolCollector_AllSixMetricsObservedFromSingleSnapshot(t *testing.T) {
    reader := sdkmetric.NewManualReader()
    mp := sdkmetric.NewMeterProvider(sdkmetric.WithReader(reader))
    meter := mp.Meter("test")

    snap := obs.PoolStatSnapshot{
        IdleConns: 3, MaxConns: 10, TotalConns: 7, AcquiredConns: 4,
        AcquireCount: 100, EmptyAcquireCount: 5,
    }
    collector, err := obs.NewPgxPoolCollector(meter, func() obs.PoolStatSnapshot { return snap })
    require.NoError(t, err)
    t.Cleanup(func() { require.NoError(t, collector.Close()) })

    var rm metricdata.ResourceMetrics
    require.NoError(t, reader.Collect(context.Background(), &rm))

    // Walk ScopeMetrics, build name→value map, assert each expected
    // metric is present with the snapshot's value.
    got := map[string]int64{}
    for _, sm := range rm.ScopeMetrics {
        for _, m := range sm.Metrics {
            switch d := m.Data.(type) {
            case metricdata.Gauge[int64]:
                for _, dp := range d.DataPoints {
                    got[m.Name] = dp.Value
                }
            case metricdata.Sum[int64]:
                for _, dp := range d.DataPoints {
                    got[m.Name] = dp.Value
                }
            }
        }
    }

    expected := map[string]int64{
        "runtime_adapters.pgx_pool.idle_conns":          3,
        "runtime_adapters.pgx_pool.max_conns":           10,
        "runtime_adapters.pgx_pool.total_conns":         7,
        "runtime_adapters.pgx_pool.acquired_conns":      4,
        "runtime_adapters.pgx_pool.acquire_count":       100,
        "runtime_adapters.pgx_pool.empty_acquire_count": 5,
    }
    for name, want := range expected {
        require.Equal(t, want, got[name], "metric %s", name)
    }
}

// TestPgxPoolCollector_CounterIsCumulativeMonotonicNotDelta verifies P3:
// when the snapshot's AcquireCount field grows from 100 to 150 between
// two collects, the OTel counter reports 150 (cumulative), NOT 50 (the
// delta). Prom rate() at query time computes the rate from cumulative
// values; emitting deltas here would double-count.
func TestPgxPoolCollector_CounterIsCumulativeMonotonicNotDelta(t *testing.T) {
    // Mutable snapshot via closure capture.
    var current obs.PoolStatSnapshot
    snapFn := func() obs.PoolStatSnapshot { return current }

    reader := sdkmetric.NewManualReader()
    mp := sdkmetric.NewMeterProvider(sdkmetric.WithReader(reader))
    collector, err := obs.NewPgxPoolCollector(mp.Meter("test"), snapFn)
    require.NoError(t, err)
    t.Cleanup(func() { require.NoError(t, collector.Close()) })

    current = obs.PoolStatSnapshot{AcquireCount: 100}
    var rm metricdata.ResourceMetrics
    require.NoError(t, reader.Collect(context.Background(), &rm))
    require.Equal(t, int64(100), readCounter(t, rm, "runtime_adapters.pgx_pool.acquire_count"))

    current = obs.PoolStatSnapshot{AcquireCount: 150}
    require.NoError(t, reader.Collect(context.Background(), &rm))
    // Expect 150 (cumulative), NOT 50 (delta).
    require.Equal(t, int64(150), readCounter(t, rm, "runtime_adapters.pgx_pool.acquire_count"))
}
```

## 5. OTel instrument map

Mapping from `pgxpool.Stat()` field → OTel name → Prom-exposed name
(after `add_metric_suffixes: true` in the OTel Collector — lesson from
G B4):

| Stat field | OTel name | Type | Prom name |
|---|---|---|---|
| `IdleConns()` | `runtime_adapters.pgx_pool.idle_conns` | Int64ObservableGauge | `runtime_adapters_pgx_pool_idle_conns` |
| `MaxConns()` | `runtime_adapters.pgx_pool.max_conns` | Int64ObservableGauge | `runtime_adapters_pgx_pool_max_conns` |
| `TotalConns()` | `runtime_adapters.pgx_pool.total_conns` | Int64ObservableGauge | `runtime_adapters_pgx_pool_total_conns` |
| `AcquiredConns()` | `runtime_adapters.pgx_pool.acquired_conns` | Int64ObservableGauge | `runtime_adapters_pgx_pool_acquired_conns` |
| `AcquireCount()` | `runtime_adapters.pgx_pool.acquire_count` | Int64ObservableCounter | `runtime_adapters_pgx_pool_acquire_count_total` |
| `EmptyAcquireCount()` | `runtime_adapters.pgx_pool.empty_acquire_count` | Int64ObservableCounter | `runtime_adapters_pgx_pool_empty_acquire_count_total` |

Counters get `_total` auto-appended. Gauges don't. The OTel names are
dotted (no double-suffix risk because none end in `.total`).

## 10. Closed decisions

Numbered as `D2C4E.<n>`.

- **D2C4E.1** — Hand-roll OTel observable instruments. NO third-party
  pgx OTel/Prometheus package. Reasoning: zero new deps, full control
  over R16 label whitelist, ~80 LOC total, matches existing repo
  observability pattern. Brainstormed 2026-05-01.
- **D2C4E.2** — Curated 6-metric set: `idle_conns`, `max_conns`,
  `total_conns`, `acquired_conns`, `acquire_count`,
  `empty_acquire_count`. NOT comprehensive (12 fields). Reasoning:
  YAGNI; covers PoolIdleZero + utilization + saturation marker.
  Adding more is a follow-up if dashboards demand.
- **D2C4E.3** — `runtime_adapters.pgx_pool.*` namespace. NO
  un-prefixed `pgx_pool_*` names. Reasoning: matches roadmap §G
  contract; matches existing `runtime_adapters.*` naming convention.
- **D2C4E.4** — Single `RegisterCallback` shares one Stat() snapshot
  across all 6 instruments. Reasoning: prevents torn-read across the
  6 fields (P2). One Stat() call per export tick.
- **D2C4E.5** — Counters emit cumulative monotonic values from
  `pgxpool.Stat()` directly. NO delta computation in the collector.
  Reasoning: this is the OTel-canonical semantic for
  `Int64ObservableCounter`. Prometheus `rate()` at query time computes
  rates from cumulatives. Computing deltas in the collector would
  double-count if the SDK's resampling cadence ever differs from the
  scrape cadence.
- **D2C4E.6** — Closure-based abstraction `PoolStatProvider func()
  PoolStatSnapshot`, NOT a `*pgxpool.Pool` direct dependency.
  Reasoning: enables true unit test (`*pgxpool.Stat` has unexported
  fields and cannot be constructed in tests). Production wraps
  `pool.Stat()` via `SnapshotFromPgx`. Per user adjustment 2026-05-01.
- **D2C4E.7** — Test naming honesty. Files named
  `pgxpool_collector_test.go` (unit, with closure fake) — NOT
  `_integration_test.go` (would imply testcontainers). The closure
  abstraction (D2C4E.6) makes this possible. Per user adjustment
  2026-05-01.
- **D2C4E.8** — Smoke verification under 2C.2 load envelope is a
  one-time manual/scripted run recorded in the CHANGELOG. NOT a
  recurring CI gate. Reasoning: matches the load-baseline calibration
  pattern; recurring gates would require a chaos-load infrastructure
  out of scope for E. Per roadmap §G exit criterion.
